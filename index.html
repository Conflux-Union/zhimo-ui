导航组件

首页 组件 导航 纸墨 ZhiMo UI 是一套个人风格的 Web Components 组件库，零依赖，可直接在任何页面中使用。 复制 src 目录到你的项目，引入 tokens.css 和 index.js 即可。 修改 tokens.css 中的设计令牌（颜色、圆角、阴影），所有组件会同步更新。
